# 김개발의 포트폴리오 — 배우고, 시도하고, 만들어 가는 중

게임과 디지털 기기를 좋아하는 제가 GitHub Copilot과 함께 만든, 파랑과 흰색의 자기소개 웹사이트예요.

## 저를 소개합니다

안녕하세요, 김개발입니다. 이곳에는 제가 좋아하는 것과 잘하는 것, 앞으로 배우고 싶은 것을 담았어요.

- **관심사와 취미:** 게임과 디지털 기기
- **강점:** 문제 해결과 기기 다루기
- **목표:** 기기와 코딩을 더 배우기

아직 자기소개 페이지에 소개할 활동이나 작품은 정해지지 않았어요. 지금은 제 관심사와 목표를 중심으로 저를 소개하고 있어요.

## 이 웹사이트를 만든 이유

친구와 선생님에게 제가 어떤 사람인지 보여주고 싶었어요. 제가 좋아하는 것과 앞으로 배우고 싶은 것을 한곳에서 읽을 수 있는 소개 페이지를 만들고자 했어요.

이 프로젝트는 GitHub Copilot과 함께 웹사이트를 만드는 초보자 실습이기도 해요. 기존 프로젝트를 바탕으로 제 이름과 소개 내용을 넣고, 원하는 색상과 화면 구성을 선택하며 저만의 공간으로 바꾸고 있어요.

## 주요 화면과 기능

| 화면·기능 | 방문자가 할 수 있는 일 |
| --- | --- |
| 홈 (`#home`) | 첫 인사말을 읽고, 버튼으로 자기소개나 포트폴리오 목록에 갈 수 있어요. |
| 자기소개 (`#/about`) | 제 관심사, 강점, 배우고 싶은 것과 목표를 차례로 읽을 수 있어요. |
| 포트폴리오 목록 (`#/portfolio`) | 현재 들어 있는 예시 프로젝트 3개를 카드로 둘러볼 수 있어요. |
| 프로젝트 상세 (예: `#/portfolio/website`) | 카드를 눌러 예시 프로젝트의 소개, 목적, 작업 과정과 배운 점을 읽을 수 있어요. |
| 페이지 이동 | 상단 메뉴와 돌아가기 링크로 화면을 옮기고, 브라우저의 뒤로 가기와 새로고침을 사용할 수 있어요. |
| 읽기와 이동을 돕는 기능 | 키보드로 본문에 바로 이동하거나, 하단의 ‘맨 위로’ 버튼으로 화면 위쪽으로 돌아갈 수 있어요. |

**포트폴리오의 프로젝트 3개와 상세 설명은 실습용 예시예요. 제가 직접 완성한 작품이나 경험을 뜻하지 않아요.** 홈의 자기소개 영역에도 아직 내용을 채우기 위한 안내 문구가 남아 있어요. 제 실제 관심사와 목표는 별도의 자기소개 페이지에서 볼 수 있어요.

사이트 전체에는 밝고 깔끔한 파랑·흰색 디자인을 적용했어요. 화면 너비에 따라 카드와 글의 배치가 바뀌도록 구성되어 있어요.

## 제작 과정과 배운 점

### GitHub Copilot과 함께 한 작업

기존 React 프로젝트를 실행하고, Copilot에게 원하는 내용을 한국어로 설명하며 수정을 요청했어요. 이름을 넣고, 자기소개 내용을 정리하고, 자기소개 페이지의 디자인을 사이트 전체에 적용하는 데 활용했어요. 포트폴리오 목록에서 필요하지 않은 안내 문구를 지우는 작업도 요청했어요.

### 제가 고민하고 선택한 부분

- 소개할 내용으로 게임·디지털 기기, 문제 해결·기기 다루기, 기기와 코딩을 더 배우려는 목표를 골랐어요.
- 밝고 깔끔한 디지털 느낌을 원해서 파랑과 흰색을 선택했어요.
- 모든 내용을 한 화면에 모으기보다, 기존처럼 자기소개를 별도 페이지로 두기로 했어요.
- 자기소개 페이지에서 사용한 디자인을 다른 화면에도 적용해 달라고 요청했어요.

이번 제작에서는 **색상과 페이지 구성을 선택하는 과정**을 경험했어요. Copilot의 도움을 받으면서도 어떤 내용과 모습으로 저를 소개할지는 제가 선택했어요.

### 어려웠던 점과 해결 과정

아직 제가 특별히 어려웠다고 느낀 점은 없어요. 그래서 이 부분에는 실제로 겪지 않은 문제나 해결 경험을 적지 않았어요.

## 사용한 기술

| 기술 | 이 프로젝트에서 하는 일 |
| --- | --- |
| React 19 | 홈, 자기소개, 포트폴리오 목록과 상세 화면을 구성해요. |
| JavaScript·JSX | 화면에 표시할 내용과 버튼의 동작을 작성해요. JSX는 JavaScript 안에서 화면 구조를 적는 문법이에요. |
| HTML·CSS | 문서의 기본 틀, 색상, 글꼴, 화면 크기별 배치를 만들어요. |
| Vite 8 | 개발 중 사이트를 실행하고, 배포에 사용할 파일을 만들어요. |
| Oxlint | 코드에서 오류 가능성과 규칙 위반을 검사해요. |
| Node.js·npm | 개발 도구를 실행하고 필요한 패키지를 설치해요. |

페이지 이동은 별도 라우터 도구 없이 주소의 `#` 뒤에 붙는 경로로 처리해요.

## 내 컴퓨터에서 실행하기

1. [Node.js 공식 사이트](https://nodejs.org/ko)에서 **Node.js 24 LTS**를 설치해 주세요. LTS는 장기 지원 버전이라는 뜻이에요. npm도 함께 설치돼요.
2. [프로젝트 저장소](https://github.com/YoonKeumJae/my-portfolio)에서 **Code → Download ZIP**으로 내려받아 압축을 풀거나, Git으로 복제해 주세요. 이미 프로젝트 폴더가 있다면 그대로 사용하면 돼요.
3. Visual Studio Code에서 **파일 → 폴더 열기**로 `package.json`이 들어 있는 프로젝트 폴더를 열어 주세요.
4. **터미널 → 새 터미널**을 누르고 아래 명령을 차례대로 입력해 주세요.

```sh
npm install
npm run dev
```

`npm install`은 처음 실행할 때 필요한 패키지를 설치하는 명령이에요. 설치가 끝나면 `npm run dev`로 개발 서버를 실행해요.

터미널에 표시되는 주소를 브라우저에서 열어 주세요. 보통 `http://localhost:5173/`이지만, 다른 주소가 표시되면 그 주소를 사용해 주세요. 서버를 종료하려면 실행 중인 터미널에서 `Ctrl + C`를 누르면 돼요.

### 코드 확인과 배포용 파일 만들기

프로젝트 폴더의 터미널에서 다음 명령을 실행할 수 있어요.

```sh
npm run lint
npm run build
```

`npm run lint`는 코드를 검사하고, `npm run build`는 배포용 파일을 `dist` 폴더에 만들어요. 빌드만으로 인터넷에 공개되는 것은 아니에요.

빌드한 결과를 내 컴퓨터에서 미리 보려면 다음 명령을 실행하고, 터미널에 표시되는 주소를 열어 주세요.

```sh
npm run preview
```

현재 자동 테스트 도구는 설정되어 있지 않아요.

### 내용을 바꿀 때 살펴볼 파일

- `src/App.jsx`: 화면 내용, 페이지 이동, 포트폴리오 예시 데이터가 있어요. `projects` 배열을 바꾸면 목록과 상세 화면에 함께 반영돼요.
- `src/App.css`: 화면별 배치와 카드·버튼 등의 모양을 정해요.
- `src/index.css`: 공통 색상과 기본 글꼴 등을 정해요.
- `index.html`: 한국어 문서 설정과 처음 표시되는 브라우저 제목이 있어요.
- `public/`: 나중에 직접 사용할 이미지 같은 파일을 둘 수 있어요.

개발 서버가 실행 중일 때 파일을 수정하고 저장하면 브라우저에 반영돼요.

## 앞으로 개선하고 싶은 점

현재는 자기소개와 포트폴리오 예시를 볼 수 있고, 전체 화면의 색상을 통일한 상태예요. 실제 작품을 소개하는 내용까지 완성된 것은 아니에요.

앞으로 무엇을 먼저 개선할지는 아직 정하지 않았어요. 직접 해본 활동이나 만든 작품을 추가할 수 있는 구성은 있지만, 구체적인 개선 계획과 순서는 나중에 정하려고 해요.
